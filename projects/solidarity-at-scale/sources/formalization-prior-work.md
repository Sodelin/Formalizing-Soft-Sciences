# References for the Lean reader guide

N01–N07 concern formalization precedents, proof checking, and dissemination. Selected S records retain their identifiers from the main research bibliography. Accessed 28 September 2026 UTC. This is a bounded comparison, not an exhaustive priority search. Repository inspection is not independent build verification.

## N01

Nipkow, Tobias (2008; journal article 2009). **Arrow and Gibbard Satterthwaite / Social Choice Theory in HOL**. Archive of Formal Proofs; Journal of Automated Reasoning 43(3), 289–304.

URL: https://isa-afp.org/entries/ArrowImpossibilityGS.html
DOI: https://doi.org/10.1007/s10817-009-9147-4

Access: AFP entry and publisher abstract/metadata. The entry describes two Arrow proofs and a Gibbard–Satterthwaite corollary in Isabelle/HOL. The author PDF request timed out; the proof development was not rebuilt here. Supports precedent for formalized social choice, not a claim about psychology.

## N02

Holliday, Wesley H., Norman, Chase, and Pacuit, Eric (2021). **Voting Theory in the Lean Theorem Prover**. LORI VIII postprint, arXiv:2110.08453.

URL: https://arxiv.org/abs/2110.08453

Access: abstract and full 17-page preprint. Describes a variable-election framework and verification of voting properties, including Split Cycle. The accompanying project was not independently rebuilt here. Supports the existence of substantive Lean social-choice formalization before this project.

## N03

Peters, Dominik, project maintainer (undated evolving repository). **SocialChoiceLean**.

URL: https://github.com/DominikPeters/SocialChoiceLean

Access: repository README. Describes Lean 4 voting rules, properties, and impossibility results. AI assistance and earlier formal work are credited by the repository. No independent proof inventory, authorship audit, or build was performed here; do not adopt any upstream novelty claim as verified.

## N04

MixedMatched, repository owner (undated evolving repository). **formalizing-game-theory**.

URL: https://github.com/MixedMatched/formalizing-game-theory

Access: repository README and source-page retrieval. The README describes a Lean game-theory development with players, actions, and payoffs. No source-level completeness audit or independent build was performed. Supports existence of prior game-theory formalization, not equivalence to the present model or validation of social behavior.

## N05

Lean project (current online reference manual). **Validating Proofs**.

URL: https://lean-lang.org/doc/reference/latest/ValidatingProofs/

This documentation tracks a newer Lean release; the actual project is pinned and verified separately at Lean 4.19.0. The project receipt, rather than current documentation, establishes its build status.
